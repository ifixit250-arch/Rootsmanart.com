ROOTSMAN ART — CAYE CAULKER COLLECTION UPDATE

Open index.html in a browser to preview the website locally.
The Caye Caulker collection now includes all eight submitted painting photographs as local assets, so the gallery does not depend on remote image hosting for these works.

The new works use “Price on request” rather than inventing sale prices. Artwork titles and descriptions are descriptive labels based on the photographs and can be edited to match the artist’s official titles.

- assets/ — the eight original uploaded images
